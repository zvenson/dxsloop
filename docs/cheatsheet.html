Die vier Spuren

1  2  3 = DX7-Synths (8 Stimmen gemeinsam)  ·  4 = Drums (6 eigene Stimmen). Jede Spur hat ihr eigenes Pattern.

Klang formen

BRITEPegel der Modulatoren: dumpf ↔ hell
ATK · DEC · RELlangsamer / länger (0 = wie programmiert)
FDBKFeedback: Sinus → Säge
ENV-SeiteATK · DEC · REL der Carrier, SUS senkt Sustain (127 = Original)
ENV/LFO DESTFLT / SHP = Helligkeit, PIT = Tonhöhe, AMP = Lautstärke

Kits (PRESETS): 1 DX KIT · 2 808 FM · 3 ELECTRO · 4 METAL · 5 USER (erste 16 Stimmen deiner Bank). Schwarze Taste = Sound links daneben. Closed/Pedal-Hat schneidet die Open-Hat ab. EDIT tippen: Grid / Kit.

Eigene DX7-Bänke (.syx)

  1. Chrome / Edge: dx7.designburgapps.com → Editor → Connect.
  2. Tab Library: „Bank in use“ 1–8 wählen, .syx (32 Stimmen, 4104 Bytes) ins Feld ziehen.
  3. Am Gerät: PRESETS 18–49 oder EDIT → Voice. Bank wechseln: EDIT → Bank.

8 Bänke × 32 = 256 Stimmen im Speicher. Original-DX7-ROMs: yamahablackboxes.com · Sammlungen: bobbyblues.recup.ch
